I'm starting to think rolling my own wide strings using Vec<IChar> as the core
would be a better implementation overall, but I'm not quite there yet. A lot of
my logic already uses them internally, and only uses the underlying strings for
u16 storage and string utility functions I haven't implemented myself (or have
implemented with a thin wrapper.) Only time will tell if this makes sense,
though - the widestring crate has been pretty useful and problem-free so far.
See IString::retain() in libs.rs for a function that may be improved by a Vec
implementation of wide strings.
